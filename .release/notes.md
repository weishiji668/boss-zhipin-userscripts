**加减乘除boss** · 6 个跑在浏览器里的求职辅助用户脚本（篡改猴 / 暴力猴 / 脚本猫任选，也可以完全不用管理器）。

## 本次更新（v0.1.1）：把界面文案统一了一遍

脚本变多以后，同一个词在不同脚本里指的不是一回事（比如「标记」在打标签脚本里是"本地画个角标"、在体检脚本里却是"已经在站内动过手了"）。这一版只动**界面文字**，逻辑、存储键、请求一律没改：

- **同名不同义的按钮分开叫**：右键隐藏后的恢复按钮统一叫「取消隐藏」；体检脚本里站内动过手的会话改叫「已处置」；watcher 的「待跟进」改叫「待处理」（聊天脚本的「待跟进」专指"我发言≥2 天没回"）。
- **一件事不再好几个名字**：watcher 卡片上的「盯岗」改成「收录」（和面板同一个词）、「立即对比」统一成「立即检查」；insight 的「隐藏词」统一成「风险词」。
- **开关/状态用词成体系**：面板入口统一叫「设置」；冷却与熔断分两档专名 ——「限流冷却（X 分钟）」和「风控熔断（到明天）」；脚本自设的额度统一叫「每日上限」，站点给的叫「站点额度」。
- **同一个词跨脚本复用，但都补了备注和用例**：「隐藏」＝只在你浏览器里藏起来、不发请求、随时可恢复（过滤脚本藏岗位卡 · 体检脚本藏会话）；「收录」＝把页面上的数据存进本机档案。
- **insight 改名**：`BOSS直聘 · 岗位体检（岗位风险词 + 聊天处置）` → **`BOSS直聘 · 聊天体检（风险词 + 一键处置）`**（它本来就只扫聊天会话）。改名后篡改猴会把它当成一份新脚本，装完请到「已安装脚本」里把旧的「岗位体检」那份删掉。

## 包含

| 脚本 | 版本 | 用途 |
| --- | --- | --- |
| boss-filter | 1.3.6 | 页面过滤：三层排除词 + 薪资范围，把噪音岗位直接隐藏 |
| boss-tag | 1.2.6 | 命中打标签：只标记不隐藏，方便人工复核 |

| boss-insight | 0.5.11 | 聊天体检：风险词扫描 + 一键处置 |
| boss-consist | 0.2.8 | 一致性体检：卡片标签 vs 详情正文矛盾 |

## 安装

见 README 的「快速开始」。6 个脚本互相独立，推荐从 `boss-filter` 开始，用顺了再加。
安装链接默认走 GitHub raw，国内不稳可以换 jsDelivr 镜像（路径一样）。

## 说明

- 所有数据只存在你本机，项目没有任何服务端。
- 唯一会写账号、也是唯一会替你发消息的 `boss-deliver`（一键投递）**不在本仓库分发**。
- 可选的 AI 判定功能需要你自己填 API Key —— 仓库里没有任何内置 key。
- 与招聘平台无关、未授权、非官方；账号风险请自行评估，请用求职专用账号。
