6 个跑在浏览器里的求职辅助用户脚本（篡改猴 / 暴力猴 / 脚本猫任选，也可以完全不用管理器）。

## 包含

| 脚本 | 版本 | 用途 |
| --- | --- | --- |
| boss-filter | 1.3.4 | 页面过滤：三层排除词 + 薪资范围，把噪音岗位直接隐藏 |
| boss-tag | 1.2.5 | 命中打标签：只标记不隐藏，方便人工复核 |
| boss-watcher | 0.9.6 | 岗位监控：建档 / 盯住 / 跟进信号 |
| boss-chat | 1.5.11 | 聊天助手：会话抓取 / 在线时间线 / 推进信号 / 复盘导出 |
| boss-insight | 0.5.10 | 会话体检：岗位风险词扫描 + 一键处置 |
| boss-consist | 0.2.7 | 一致性体检：卡片标签 vs 详情正文矛盾 |

## 安装

见 README 的「快速开始」。6 个脚本互相独立，推荐从 `boss-filter` 开始，用顺了再加。
安装链接默认走 GitHub raw，国内不稳可以换 jsDelivr 镜像（路径一样）。

## 说明

- 所有数据只存在你本机，项目没有任何服务端。
- 唯一会写账号、也是唯一会替你发消息的 `boss-deliver`（一键投递）**不在本仓库分发**。
- 可选的 AI 判定功能需要你自己填 API Key —— 仓库里没有任何内置 key。
- 与招聘平台无关、未授权、非官方；账号风险请自行评估，请用求职专用账号。
