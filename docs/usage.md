# 怎么用：六个场景

这份文档不讲实现，只讲「什么时候点哪个按钮」。每个脚本的权限与本机数据键见 [scripts/](scripts/README.md)。

## 场景 0：先把噪音挡掉（boss-filter）

1. 打开职位列表页，左下角会出现状态条：「已过滤 x / y ｜ 显示被过滤 ｜ 规则 ｜ 关闭过滤」。
2. 点「规则」，分三层填排除词：
   - **绝对**：命中即隐藏（例如「电销」「外包」「培训费」）
   - **卡片**：只看列表卡片上的字段（公司名、地点、学历标签）
   - **详情**：只看岗位正文（需要先取到详情；没有缓存时不会按空值误判）
3. 点「显示被过滤」自检一遍：被藏起来的卡片会显示出来并标红，确认没误伤再关掉。
4. 在卡片上右键还能：隐藏这一条 / 把选中的词加进排除词 / 把公司加进黑名单。

> `boss-filter` 默认不发任何请求；只有你点「补取详情」时，才按需读取岗位正文。

## 场景 1：标出真正想要的（boss-tag）

- 规则是**正向**的：地区（想去的城市）/ 关键词 / 公司名 / 起步月薪。命中的卡片被打上橙色胶囊，**不隐藏任何东西**。
- 复核时右键胶囊可「取消标记」，名单落盘，之后不会再被打标。
- 「隐藏未命中」是可选玩法：先打标 → 人工复核 → 点按钮把没命中的藏起来，剩下的就是你真要看的。
  若开着这个开关但规则全空，脚本会暂停隐藏并提示（避免把整页藏光）。

## 场景 2：盯住心仪岗位（boss-watcher）

1. 右下角 💼 打开面板 → 粘贴「公司名 + 职位名」→ 收录（会发 1 次站内搜索 + 1 次详情请求）。
2. 之后你正常浏览时，它用页面实时数据对比：**薪资下调 / 要求拔高 / HR 换人 / 突然下线**，写进变更日志。
3. 「跟进信号」是待办清单；「变更日志」是原始流水，可导出 JSON 备份。

## 场景 3：主动出击（一键投递 · 不在本仓库）

本仓库不包含 `boss-deliver` —— 它是唯一会写账号、也是唯一会替你发消息的脚本，公开版只保留只读脚本。如果你已经拿到它：确认想要的岗位在列表页**可见**（被 filter 隐藏的不会被投）→ 点小条上的 📤 → 确认「缺接口数据」为 0 → 点「投递本页」开始（默认每岗约 10 秒、每岗在 0.7~1.3 倍之间随机，每天最多 50 个，随时可停）。撞到站点额度会熔断或冷却，面板会给明确文案，第二天自动恢复。

## 场景 4：收工复盘（boss-chat + boss-insight）

- 💬 聊天助手面板顶上是三张卡：**该你回 / 该催 / 已有联系方式**；会话列表带 24 格活跃条（看得出 HR 什么时候在线）。
- 导出有 5 种表：投递复盘 CSV / 消息明细 CSV / JSONL / 聊天备份 JSON 等，命名统一是「日期时间-用途-脚本」。
- 🩺 会话体检按你设的风险词扫**对方发来的消息**，命中的会话打「风险」标记；处置按钮（本地隐藏 / 标不感兴趣 / 拉黑 / 删除）
  只在你点击时执行，其中拉黑与删除**不可逆**，并受每日上限与同会话冷却约束。

## 场景 5：防坑（boss-consist）

- 比对「卡片小标签」与「详情正文」，挑三类矛盾：学历（卡片大专 / 正文本科）、经验（卡片不限 / 正文 1 年以上）、
  正文里的硬要求（四六级、证书、小语种）。
- 状态条两个按钮：「隐藏」批量隐藏命中卡、「标记」只打胶囊；右键可取消某张卡的标记。
- 面板里的「手动对比」两个框可以贴任意文本做离线对比（不联网、不打标）。

## 日常节奏建议

| 时机 | 做什么 |
| --- | --- |
| 换关键词搜索时 | 看一眼 filter 状态条，确认过滤规则仍然合适 |
| 每天开工 | 滚一遍列表页，让 watcher 建立索引、filter 把噪音挡掉 |
| 每天收工 | 消息页看一眼 chat 的三张卡 + insight 的风险标记 |
| 每周 | 导出一次复盘表；核对 watcher 的跟进信号有没有过期 |

## 数据与导出

所有数据只在本机，导出文件默认落在下载目录。**别把带个人信息的导出文件（HR 姓名、联系方式、你的投递记录）发到公开 issue 里。**
